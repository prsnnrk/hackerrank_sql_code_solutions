README: I create a Common Table Expression (CTE) called wands_details, with the temporary result set of the wands table joined with the wands_property table with the joining key as code, where it matches from one table to the other. It is also filtering out the evil wands, and I have added an additional column of ROW_NUMBER(), which is PARTITIONED BY power, followed by age, and is ordered by coins_needed in ascending order. This means that the wand records with the same power and the same age values will be assigned row numbers sequentially as part of a set of similar records, in terms of power and age values. The values queried here are the id, age, coins_needed and power, all denoting the characteristics of the wands. From this CTE, I then SELECT the same list of column values, except I limit the records displayed to that of only records with the row number of 1. This basically means for wands which have the same power and age values, the wand record chosen is the one with the lowest value of coins needed. I order this result by ascending power values, followed by descending age values.
