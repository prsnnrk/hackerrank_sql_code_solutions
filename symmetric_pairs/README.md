README: I create 2 identical CTEs, to pretty much add a row_num to all the records in each CTE. Then, I create a CTE, called symmetric_condition_check which gets the result set of the first CTE earlier, joined with the second CTE, with the matching joining key as the symmetric condition check which is whether the X value from the first CTE matches with the Y value of the second CTE, and whether the Y value of the first CTE matches with the X value of the second CTE. This is with the filtering condition where the row_num on both records being compared cannot be identical, as in although the values could be coincidentally the same from two different records, this solution makes sure that no 2 exact same records are being checked against each other, with the help of the row_number record identification. Then, I proceed to splitting the symmetric pairs down to only one pair of X and Y values per row with the help of the UNION operator, which also helps to filter out duplicate record values, without using UNION ALL. Then, I SELECT the X and Y values from the latest CTE, symmetric_pairs_split, and pass it through a WHERE clause condition check to make sure that the X value is not greater than its corresponding Y value, and finally, I ORDER the records by ASCENDING ORDER of the X value.
