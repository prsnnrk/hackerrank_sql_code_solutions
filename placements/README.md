README: I create a CTE called best_friends to associate the student with their best friend, by mapping the student's id which matches in both students and friends table. I then proceed to create another CTE, called student_salary, which extracts the salary detail of the student by joining the earlier CTE with the packages table ON the student's id as the joining key. After that, I create a CTE called best_friend_salary to extract the salary detail of the student's best friend by joining the student_salary CTE with the packages CTE once more, except this time, the joining key is no longer the student_id, it is based on the friend_id. From there, I SELECT the names of the students whose best friends' salaries are higher than them by applying a WHERE clause condition, and this is followed by an ORDER BY specification to sort the names in ASCENDING ORDER of their best friends' salaries.
